# HIC-Hackathon

Minimal starter for:
- Vite + React + TypeScript
- Tailwind CSS
- Supabase client setup
- Gemini API key wiring
- Vercel deployment config

## Setup

1. Install dependencies:
   - `npm install`
2. Create local env file:
   - copy `.env.example` to `.env.local`
3. Fill env values:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   - `VITE_GEMINI_API_KEY`
4. Run app:
   - `npm run dev`

## Build

- `npm run build`
- `npm run preview`
